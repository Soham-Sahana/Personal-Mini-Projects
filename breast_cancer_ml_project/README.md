# Breast Cancer Classification Using Machine Learning

**Project type:** Binary classification  
**Dataset:** Breast Cancer Wisconsin (Diagnostic), UCI Machine Learning Repository  
**Purpose:** Academic comparison of ML algorithms, model evaluation, tuning, EDA and Streamlit deployment.

> **Important:** This project is for education only. It is not a medical device or diagnostic service and must not be used for healthcare decisions.

## Dataset

- Official source: https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic
- 569 samples and 30 numerical predictors; two target classes.
- The project uses `sklearn.datasets.load_breast_cancer`, a public copy of the UCI dataset, for reproducible loading without a manual download.
- The target is recoded so `malignant = 1` and `benign = 0`. This makes malignant the positive class for recall and ROC-AUC.

## Run locally

Python 3.10 or newer is recommended.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python train.py
streamlit run app.py
```

Run `python train.py` first. It generates the EDA figures, baseline comparison, tuned result, classification report and serialized model.

## Methodology

- 80/20 stratified train/test split with `random_state=42`.
- Five models: Logistic Regression, Decision Tree, Random Forest, Support Vector Machine and Gradient Boosting.
- Imputation/scaling steps are inside pipelines so fitted preprocessing uses training data only.
- The same held-out test set is used for all baseline comparisons.
- GridSearchCV with 5-fold stratified CV tunes the best baseline model using training data only. The test set is reserved for final evaluation.
- Metrics: accuracy, precision, recall, F1 and ROC-AUC. The positive class is malignant.

## Streamlit Community Cloud deployment

1. Push the project to GitHub.
2. Open https://share.streamlit.io/ and sign in.
3. Select the repository, branch `main`, and main file path `app.py`.
4. Deploy. The first deployment must also run `python train.py` to generate `artifacts/best_model.joblib`; the simplest workflow is to run training locally and commit the generated `artifacts/` files, or change the app deployment workflow to train automatically at startup.
5. If committing generated model artifacts, ensure the Python/scikit-learn versions used to train and deploy are compatible.
