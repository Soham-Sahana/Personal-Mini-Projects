## Abstract

This project compares supervised machine-learning classifiers for distinguishing benign from malignant breast masses using the Breast Cancer Wisconsin (Diagnostic) dataset. The workflow includes exploratory data analysis, data-quality checks, leakage-safe preprocessing, a stratified train/test split, baseline model comparison, cross-validated hyperparameter tuning, evaluation using classification metrics, and a Streamlit demonstration interface. The models are Logistic Regression, Decision Tree, Random Forest, Support Vector Machine, and Gradient Boosting. Results must be populated from the reproducible experiment generated by `python train.py`; no model score is assumed in advance. The project is educational and is not intended for clinical diagnosis.

## 1. Literature Review

Wolberg, Street and Mangasarian developed and studied numerical descriptors extracted from digitized fine-needle aspirate images. The dataset has become a commonly used benchmark for binary classification. Linear classifiers such as Logistic Regression provide a useful interpretable baseline; decision trees model nonlinear rules; Random Forest averages many trees to reduce variance; Support Vector Machines can separate classes in a transformed feature space; and Gradient Boosting sequentially improves an ensemble of weak learners. Their comparative performance depends on data characteristics, preprocessing, split strategy and hyperparameters, so evaluation should use a consistent experimental protocol.

## 2. Introduction and Problem Statement

Breast mass diagnosis is a high-impact classification task. This assignment explores whether numerical cell-nucleus measurements can be used by supervised algorithms to classify examples as benign or malignant. ## 4. Dataset Description

**Name:** Breast Cancer Wisconsin (Diagnostic)  
**Source:** https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic  
**DOI:** https://doi.org/10.24432/C5DW2B  
**Observations:** 569  
**Predictors:** 30 continuous numerical features  
**Target:** Diagnosis, benign or malignant  
**Class counts:** 357 benign and 212 malignant.

The features describe ten properties of cell nuclei—radius, texture, perimeter, area, smoothness, compactness, concavity, concave points, symmetry and fractal dimension—represented by mean, standard-error and worst-value measurements. The implementation loads the publicly distributed copy from scikit-learn, which excludes the original identifier column.

## 6. Data Preprocessing

- The target is recoded as `malignant = 1`, `benign = 0`, so malignant is the positive class.
- A stratified 80% training / 20% test split uses random state 42.
- Median imputation is placed inside each model pipeline. The supplied dataset is expected to have no missing predictor values, but the step makes the pipeline robust.
- StandardScaler is applied inside the Logistic Regression and SVM pipelines. Trees do not require feature scaling, so their pipelines omit the scaler.
- Preprocessing is fitted only on training folds by scikit-learn pipelines and cross-validation.
- No automatic outlier deletion is performed; it could remove meaningful cases.

## 7. Machine Learning Algorithms Implemented

1. **Logistic Regression:** linear probabilistic baseline with balanced class weights.
2. **Decision Tree:** nonlinear rule-based classifier.
3. **Random Forest:** bagged tree ensemble.
4. **Support Vector Machine:** margin-based classifier using an RBF default kernel.
5. **Gradient Boosting:** sequential ensemble of shallow decision trees.

All five models use the same training/test split and are evaluated on the same held-out test records.

## 8. Experimental Setup and Workflow

**Caution:** Selecting a model based on test ROC-AUC can introduce test-set selection bias. **Observed results from this run:** the baseline SVM achieved the highest accuracy (0.9825), F1 (0.9762) and malignant recall (0.9762). Its ROC-AUC improved slightly, while accuracy, recall and F1 were lower than the untuned SVM and some baseline scores. Tuning is therefore not a universal improvement across metrics. ## 10. Hyperparameter Tuning

GridSearchCV searches a model-specific parameter grid using five-fold stratified cross-validation on the training data. The scoring metric is ROC-AUC. The chosen estimator is refitted on all training data, then evaluated on the held-out test set. The exact parameter grid, best cross-validation ROC-AUC and tuned test metrics are saved in `results/tuning_summary.json`.
